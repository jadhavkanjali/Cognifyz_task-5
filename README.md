# Cognifyz Advanced API Integration Dashboard

**Task 5 – Level 4: Expert**

Developed by **Anjali Jadhav** for **Cognifyz Technologies**.

## About
A responsive weather dashboard that integrates the OpenWeather API using Node.js and Express.js.

## Features
- Live weather information by city
- Secure API key management using `.env`
- API rate limiting and error handling
- Responsive HTML, CSS and JavaScript interface

## Technologies
HTML, CSS, JavaScript, Node.js, Express.js and OpenWeather API.

## Setup
1. Install Node.js.
2. Run `npm install`.
3. Add your API key to `.env`.
4. Run `npm start`.
5. Open `http://localhost:3000`.
